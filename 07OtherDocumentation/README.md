Project Overview



ProvStock is a comprehensive, desktop-based sales and inventory management system developed in Java for Prov\&Tec, an electrical materials distributor in Ecuador. The application was built to modernize and replace manual, paper-based workflows by centralizing product catalogs, customer records, supplier management, and sales history. Featuring real-time automated stock updates, low-stock alerts, role-based access control, class-specific JSON data persistence, and CSV report exports, ProvStock provides a streamlined, reliable solution to optimize daily store operations and support data-driven decision-making.
